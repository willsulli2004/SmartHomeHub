# Enclosure

STEP files for the hub's 3D printed enclosure, exported from Fusion 360. They are copies of Will's
working files, added on November 23rd, 2026; the CAD source stays in Fusion 360.

| File | Part |
|---|---|
| `step/Assembly2.0.step` | The full assembly |
| `step/Base2.0.step` | Base |
| `step/BaseTop2.0.step` | Base top |
| `step/ESPHolder.step` | ESP32 holder |
| `step/LED_Holder.step` | LED holder |
| `step/LEDCone.step` | LED cone |
| `step/SpeakerHolder.step` | Speaker holder |
| `step/VolumeRing.step` | Volume ring (ring gear) |
| `step/PinionGear.step` | Planet gear (two are printed) |
| `step/EncoderGear.step` | Sun gear, on the encoder shaft |

The volume ring, planet gears and sun gear form the planetary gearbox that turns the rotary encoder.
